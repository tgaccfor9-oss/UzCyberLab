# UzCyberLab

UzCyberLab — kiberxavfsizlikni o‘zbek tilida amaliy mashqlar orqali o‘rganish loyihasi.

## Nimalarni o‘rganaman?

- Tarmoq asoslari: IP manzil, DNS va portlar
- Linux buyruqlari
- Python bilan xavfsizlikka oid kichik dasturlar
- Shubhali faoliyatni aniqlash va tahlil qilish

## Birinchi mashq

IP manzil, DNS va portlar qanday ishlashini o‘rganaman va natijalarni shu loyihaga yozaman.
